Privacy

Single Purpose

Spoiler Shield automatically hides news and content related to topics selected by the user (TV series, shows, sporting events, etc.) while they browse the web, helping them avoid unwanted spoilers.

Permissions

storage

This permission is used to save the list of blocked topics and per-site exceptions locally on the user's device. No data is synchronized elsewhere.

activeTab

This permission is used only to read the URL of the active tab when the user opens the extension's popup, so the “exclude this site” option can be displayed. It is not used to read other tabs or browsing history.

Host permissions (content script on http(s)://*/*)

The extension needs to examine text on web pages (headlines, previews, and image alternative text) to compare it with the topics the user has chosen to block. Because a spoiler may appear on any news site, social platform, or forum, this feature requires access to all HTTP and HTTPS pages. A narrower set of sites would not cover this use case. All matching takes place locally in the browser: page content is not collected, saved, or sent elsewhere.

Remote Code Declaration

The extension does not download or execute any remote code. All JavaScript code is included in the uploaded package and is readable in plain text, without minification or obfuscation.

Data Use / Privacy Practices FAQ

  • Does the extension collect personal data? No.
  • Is data transmitted to external servers? No. Everything remains in chrome.storage.local on the user's device.
  • Web page content (text and headlines) is read and processed only in memory, locally, to compare it with blocked topics. It is never saved or transmitted.
  • Is data sold to third parties? Not applicable: we do not collect data.
  • Is data used for purposes unrelated to the stated purpose, such as advertising, profiling, or credit and lending decisions? No.

Declaration — Spoiler Shield

Spoiler Shield does not collect personal data, store it on external servers, or transmit it. Blocked topics, per-site exceptions, and the selected language are stored exclusively on the user's device through Google Chrome's chrome.storage.local API.

To identify spoilers, the extension analyzes the text of visited web pages (headlines, previews, and image text) entirely within the user's browser. This content is never collected, recorded, shared, or sent to MK Web Studio or any third party.

The use of information received through Google APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements.
